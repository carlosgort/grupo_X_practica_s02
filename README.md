# Sistema Experto Explicable y Lógica Difusa - Centro Logístico

Proyecto desarrollado para la práctica S02 del módulo de Inteligencia Artificial.

## 1. Integrantes del Grupo (4 Personas)
* **Integrante 1:** Motor de reglas e inferencia (`motor_reglas.py`)
* **Integrante 2:** Lógica difusa y ciclo Mamdani (`logica_difusa.py`)
* **Integrante 3:** Interfaz de consola y aplicación Streamlit (`main.py` / `app.py`)
* **Integrante 4:** Casos de prueba, regla propia, memoria e informe técnico
